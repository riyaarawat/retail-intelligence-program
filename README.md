# retail-intelligence-system
End-to-end retail analytics and machine learning platform using Python, SQL, Power BI, Tableau, and Scikit-learn.

## What This Project Does

This project analyzes retail sales data for a fictional supermarket chain (FreshMart) to answer key business questions:

- Which products and categories drive the most revenue?
- Who are our most valuable customers?
- Which customers are at risk of churning?
- What will sales look like next month?

## Tools & Technologies

- **Python** — Data processing, analysis, machine learning
- **PostgreSQL** — Relational database and SQL analytics  
- **Power BI** — Business intelligence dashboard
- **Pandas, NumPy** — Data manipulation
- **Matplotlib, Seaborn** — Data visualization
- **Scikit-learn** — Machine learning models
